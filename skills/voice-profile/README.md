# @meir-labs/skill-voice-profile

The meirlabs writing-voice skill — hard rules, tone, and never-use lists so drafts sound like one person instead of a model.

## Install

```sh
# into the current project (./.claude/skills/voice-profile)
npx @meir-labs/skill-voice-profile

# into every project (~/.claude/skills/voice-profile)
npx @meir-labs/skill-voice-profile --global
```

Pass `--force` to overwrite an existing copy. Claude Code picks the skill up automatically when drafting or reviewing emails, posts, and proposals in the meirlabs voice.

The skill is plain markdown — read it before you run it: [`files/`](./files).
Full page: [meirlabs.com/skills/voice-profile](https://meirlabs.com/skills/voice-profile).
