# @meir-labs/skill-ui-kit

The usage skill for @meir-labs/ui-kit — when tables, pagination, status pills, tags, or metrics come up, reach for the kit instead of rebuilding.

## Install

```sh
# into the current project (./.claude/skills/ui-kit)
npx @meir-labs/skill-ui-kit

# into every project (~/.claude/skills/ui-kit)
npx @meir-labs/skill-ui-kit --global
```

Pass `--force` to overwrite an existing copy. Claude Code picks the skill up automatically when building UI with tables, pagination, status pills, tags, or metric values.

The skill is plain markdown — read it before you run it: [`files/`](./files).
Full page: [meirlabs.com/skills/ui-kit](https://meirlabs.com/skills/ui-kit).
