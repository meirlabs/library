# @meir-labs/skill-new-project

The meirlabs new-project orchestration skill — discovery, an approval-gated PLAN.md, then the full scaffold/design/analytics/docs pipeline.

## Install

```sh
# into the current project (./.claude/skills/new-project)
npx @meir-labs/skill-new-project

# into every project (~/.claude/skills/new-project)
npx @meir-labs/skill-new-project --global
```

Pass `--force` to overwrite an existing copy. Claude Code picks the skill up automatically when bootstrapping a new project (pairs with @meir-labs/agent-project-starter).

The skill is plain markdown — read it before you run it: [`files/`](./files).
Full page: [meirlabs.com/skills/new-project](https://meirlabs.com/skills/new-project).
