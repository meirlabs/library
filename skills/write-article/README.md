# @meir-labs/skill-write-article

The house method for writing SEO/AEO articles — the answer-engine structure, tiered numbers with concrete examples, a "By the numbers" stats convention, and the editorial rules that keep every piece consistent.

## Install

```sh
# into the current project (./.claude/skills/write-article)
npx @meir-labs/skill-write-article

# into every project (~/.claude/skills/write-article)
npx @meir-labs/skill-write-article --global
```

Pass `--force` to overwrite an existing copy. Claude Code picks the skill up automatically when you ask it to write or edit an article.

The skill is plain markdown — read it before you run it: [`files/`](./files).
Full page: [meirlabs.com/skills/write-article](https://meirlabs.com/skills/write-article).
