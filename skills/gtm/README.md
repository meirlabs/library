# @meir-labs/skill-gtm

How a one-person studio takes an idea to market — positioning, channels, and operating cadence, as a Claude Code skill.

## Install

```sh
# into the current project (./.claude/skills/gtm)
npx @meir-labs/skill-gtm

# into every project (~/.claude/skills/gtm)
npx @meir-labs/skill-gtm --global
```

Pass `--force` to overwrite an existing copy. Claude Code picks the skill up automatically when planning launches, landing pages, or distribution.

The skill is plain markdown — read it before you run it: [`files/`](./files).
Full page: [meirlabs.com/skills/gtm](https://meirlabs.com/skills/gtm).
