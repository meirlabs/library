# @meir-labs/skill-design

The meirlabs design rules for a product's visual layer — brand tokens, fixed structure, and the rules everything defers to. A Claude Code skill;

## Install

```sh
# into the current project (./.claude/skills/design)
npx @meir-labs/skill-design

# into every project (~/.claude/skills/design)
npx @meir-labs/skill-design --global
```

Pass `--force` to overwrite an existing copy. Claude Code picks the skill up automatically when styling any app in the meirlabs family.

The skill is plain markdown — read it before you run it: [`files/`](./files).
Full page: [meirlabs.com/skills/design](https://meirlabs.com/skills/design).
