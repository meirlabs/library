# @meir-labs/skill-principles

The values and 5-Step Process that guide the work at meirlabs, as a Claude Code skill.

## Install

```sh
# into the current project (./.claude/skills/principles)
npx @meir-labs/skill-principles

# into every project (~/.claude/skills/principles)
npx @meir-labs/skill-principles --global
```

Pass `--force` to overwrite an existing copy. Claude Code picks the skill up automatically when decisions about priorities, quality bars, and handling mistakes.

The skill is plain markdown — read it before you run it: [`files/`](./files).
Full page: [meirlabs.com/skills/principles](https://meirlabs.com/skills/principles).
