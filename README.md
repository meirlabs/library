# meirlabs library

Public mirror of the [meirlabs](https://meirlabs.com) Claude Code **skills** and
**agents**. Each folder under `skills/` and `agents/` is one installable
package — the same artifact published to npm as `@meir-labs/skill-<name>` /
`@meir-labs/agent-<name>`.

Browse a skill or agent on the site and use its **GitHub** link to jump straight
to its folder here.

> This repository is generated from the meirlabs monorepo. Do not edit it
> directly — changes are overwritten on the next sync.
